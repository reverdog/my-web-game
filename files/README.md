# 잔향 (아이폰 Safari용)

## 처음 올리기 (GitHub 웹, 약 5분)
1. github.com 로그인 → 우상단 **+ → New repository** → 이름 `janhyang`, **Public** → Create repository
2. 저장소 화면에서 **uploading an existing file** → 이 폴더의 파일 5개(index.html, manifest.webmanifest, icon-180.png, icon-512.png, .nojekyll)를 모두 올리고 **Commit changes**
3. **Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save**
4. 1~2분 뒤 `https://내아이디.github.io/janhyang/` 주소가 생깁니다.
5. 아이폰 Safari에서 열고 **공유 → 홈 화면에 추가**. 전체화면으로 실행되고 저장 데이터도 더 안전합니다.

## 업데이트할 때
새 `index.html`을 같은 방법(Add file → Upload files)으로 올리면 같은 이름이라 덮어써지고, 1~2분 뒤 같은 주소에 반영됩니다. 주소가 그대로라 영구 재화·계정 레벨·도감·도전 과제와 진행 중인 런이 유지됩니다.
